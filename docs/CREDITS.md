# Development credits

The Kiroween grant offers 4,000 Kiro development credits to approved entrants,
subject to availability. Registration and a completed request do not establish
that credits have been granted or redeemed.

- Official resources: https://kiroween.devpost.com/resources
- Request deadline: December 1, 2026, 2 PM Central / noon Pacific.
- Redeem an approved code by December 4; grant credits expire December 31.
- Requests are reviewed in weekday batches and can require identity verification.
- Read the current official instructions for exact processing and expiry details.

Kiro credits pay for development assistance. A deployed AI guide needs a separately
chosen inference service and budget. Record balances only when actually observed.

Keep user IDs, grant codes, identity documents, and private emails outside this
public repository. Repository setup used no Kiro credits and configured no provider.
